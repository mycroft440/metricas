# métricas

App Android para medir com precisão o **tempo de tela desbloqueada** por dia, guardar o
histórico por data e calcular médias confiáveis. Toda data e hora é obtida **pela internet**
(TrustedTime/NTP.br), não pelo relógio do aparelho.

- Plano completo (pesquisa, definição da métrica, hora pela internet, arquitetura,
  algoritmo, médias, validação): [`docs/PLANO_TEMPO_DE_TELA.md`](docs/PLANO_TEMPO_DE_TELA.md)
